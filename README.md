## 🚀 How to Run Any Problem

1. Checkout the desired session branch:
   ```bash
   git checkout feature/session1
   ```
2. Navigate to either `assignment` or `practice_problem`:
   ```bash
   cd assignment
   # or
   cd practice_problem
   ```
3. Compile and execute any Java file:
   ```bash
   javac <FileName>.java
   java <FileName>
   ```
